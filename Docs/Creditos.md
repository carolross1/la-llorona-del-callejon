# Créditos y Atribuciones

**Videojuego:** La Llorona del Callejón  
**Género:** Terror y Sigilo 2D Top-Down  
**Institución:** Universidad Tecnológica del Norte de Guanajuato (UTNG)  
**Materia:** Desarrollo de Videojuego 2D/3D — Unidad 2  

---

## 1. Equipo de Desarrollo

* **Carol Ross** — Programación de sistemas, arquitectura de software, inteligencia artificial y control de versiones.
* **Princes** — Diseño de niveles, sonorización, narrativa, guion y ensamble de arte.

---

## 2. Declaración de Arte Generativo con Inteligencia Artificial

Siguiendo las políticas académicas y de transparencia tecnológica, se declara que los recursos visuales base (sprites de personajes, hojas de props, fachada colonial y tiles de entorno) fueron generados utilizando herramientas de **Inteligencia Artificial Generativa de Imágenes** (Midjourney / Stable Diffusion / DALL-E) y posteriormente ajustados, escalados a 192 PPU y recortados en Unity Sprite Editor por el equipo de desarrollo.

---

## 3. Herramientas y Tecnologías Utilizadas

* **Motor de Videojuego:** Unity 6.6 (versión 6000.6.0f1), plantilla Universal 2D (URP).
* **Lenguaje:** C# (.NET Standard 2.1).
* **Entrada de Controles:** Unity Input System (versión 1.20.0).
* **Control de Versiones:** Git y GitHub.
* **Tipografías:** Legacy Runtime UI Font (uGUI).
