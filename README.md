# La Llorona del Callejón

Videojuego 2D de terror y sigilo top-down ambientado en Dolores Hidalgo, Gto.
Proyecto de la materia de Desarrollo de Videojuegos 2D/3D (UTNG).

## Integrantes
- Rios Rios Carol Guadalupe
- Guerrero Sánchez Princes Rocio

## Tecnologías
- Unity 6.6 (2D URP)
- C#
- Git y GitHub

## Controles
| Tecla | Acción |
|---|---|
| WASD / Flechas | Moverse |
| Shift | Correr  |
| E | Esconderse / salir del escondite |

## Cómo abrir el proyecto
1. Clonar el repositorio.
2. Abrir la carpeta con Unity Hub (Unity 6.6).
3. Abrir la escena `Assets/Scenes/Level1_Mercado`.
4. Presionar Play.
